# PRD: 做一个调用TTS生成音频的工具

## Executive Summary

开发一个基于豆包TTS API的音频生成工具，为内部用户提供便捷的文本转语音服务。该工具将通过直观的Web界面，支持文本导入、语音配置、批量生成等功能，实现高效的音频内容生产。系统采用Python后端 + Web前端架构，确保专业性和易用性的平衡。

## Problem Statement

### 当前痛点
1. **手动调用API效率低下**: 直接使用API需要编程知识，对非技术用户不友好
2. **批量处理困难**: 缺乏批量文本转换能力，大量文本需要逐个处理
3. **配置管理繁琐**: 每次调用需要手动设置各种参数，容易出错
4. **文件管理混乱**: 生成的音频文件缺乏有效的命名和组织方式

### 为什么现在需要解决
- 内部内容创作需求增加，需要快速生成音频内容
- 提高工作效率，减少重复性工作
- 标准化音频生成流程，确保输出质量一致

## User Stories

### 主要用户角色
**内容创作者**: 需要将文档、文章转换成音频的内部员工

### 用户故事

**作为**内容创作者

#### 故事2: 灵活的语音配置
**作为**内容创作者

**以便**创作符合内容风格的音频  

**验收标准**:
- 可视化选择语音角色
- 支持情感风格选择
- 实时调节语速、音调、音量
- 支持配置预设保存

#### 故事3: 智能文件管理
**作为**内容创作者  
**我想要**自定义音频文件名和输出位置  
**以便**更好地组织管理生成的文件  

**验收标准**:
- 支持自定义文件名

## Requirements

### Functional Requirements

#### 1. 文本输入管理
- **文档导入**: 支持txt、docx、pdf格式文档导入
- **直接输入**: 提供文本编辑区域，支持复制粘贴
- **批量处理**: 
  - 按行分割模式：每行生成独立音频文件
  - 按段落分割：根据空行分割段落
  - 自定义分割：支持自定义分隔符
- **文本类型**: 支持纯文本和SSML标记语言

#### 2. 语音配置系统
- **音色选择**:
  - 基于voice_config.json的分类展示
  - 支持按场景筛选（通用、有声书、助手、视频、特色等）
  - 支持按语言筛选（中文、英语、日语、方言等）
  - 显示音色预览和特征说明
- **情感控制**: 动态加载对应音色的可用情感选项
- **音频参数**:
  - 语速调节：0.2-3.0倍速，步进0.1
  - 音调调节：0.1-3.0，步进0.1
  - 音量调节：0.1-3.0，步进0.1
  - 采样率选择：8000/16000/24000 Hz
  - 编码格式：MP3、WAV、PCM、OGG_OPUS
- **高级设置**:
  - 句尾静音时长
  - 时间戳返回选项
  - Emoji过滤开关
  - 英文优化选项

#### 3. 文件管理
- **命名系统**:
  - 默认命名：时间戳+序号
  - 自定义命名：支持在文本旁输入对应文件名
  - 批量命名模板：支持变量替换（日期、序号、音色等）
- **输出管理**:
  - 自定义输出文件夹
  - 自动创建日期子文件夹
  - 支持按音色/语言分类存储

#### 4. 批处理引擎
- **队列管理**: 
  - 显示待处理队列
  - 支持暂停/继续/取消
  - 失败重试机制
- **进度显示**:
  - 总体进度条
  - 当前处理项高亮
  - 预计剩余时间
- **并发控制**: 可配置并发数（1-5）

#### 5. 成本控制
- **字数限制**:
  - 单次请求超1000字弹出确认
  - 单次请求硬限制5000字
  - 显示当前批次总字数
- **使用统计**:
  - 今日使用量
  - 本月累计
  - 历史记录查询

### Non-Functional Requirements

#### 性能要求
- **响应时间**: 
  - 界面操作响应 < 200ms
  - API调用超时设置：60秒

#### 可用性
- **界面设计**:

  - 响应式布局，支持不同屏幕
  - 暗色/亮色主题切换
- **操作引导**:
  - 首次使用引导
  - 工具提示说明
  - 快捷键支持

#### 可维护性
- **配置管理**:
  - 基于JSON的配置文件
  - 热重载配置
  - 配置版本管理
- **日志系统**:
  - 分级日志（DEBUG/INFO/ERROR）

## Constraints & Assumptions

### 技术约束
1. **API限制**:
   - 豆包TTS API的请求频率限制
   - HTTP接口60秒超时限制
   - 单次文本长度限制（1024字节UTF-8，复刻音色除外）

2. **环境要求**:
   - Python 3.8+
   - 现代浏览器（Chrome 90+, Firefox 88+, Safari 14+）
   - 稳定的网络连接

### 业务约束
1. **仅供内部使用**，不对外开放
2. **API密钥**由IT部门统一管理
3. **存储空间**需要预先规划和分配

### 假设
1. 用户具备基本的计算机操作能力
2. 豆包TTS API服务持续可用
3. 生成的音频文件本地存储，不上传云端
4. 用户负责内容版权合规性
